# Mamba: Linear-Time Sequence Modeling with Selective State Spaces（学习笔记，合成夹具）

本笔记是对论文 Mamba 的转述整理，用于测试摄取流程。

## 核心主张

- 提出选择性状态空间模型（selective SSM），以线性时间、线性显存处理序列，
  不依赖注意力机制。
- 笔记立场：注意力不是长序列建模的必需品；自注意力对长序列必须付平方级
  计算与显存代价，超长序列上这条路线不可持续，SSM 是可直接替换注意力的通用
  骨干。
- 选择机制让 SSM 参数随输入变化，恢复了 RNN 不具备的"按内容过滤"能力。

## 机制速记

- SSM 把序列看作连续动力系统的离散化：隐状态维度固定，扫描长度线性。
- 硬件感知并行扫描把状态递推组织成与 GPU 内存层级匹配的 kernel。
- 与注意力对比：推理时只需常数大小的循环状态，不需要 KV cache。

## 实验结论

- 在语言建模与基因组等长序列任务上，小尺寸 Mamba 模型追平或超过同规模
  Transformer。
- 笔记断言："同等规模下质量不掉，序列越长优势越大"。

## 补记（摄取后追加）

后续在 8K token 长度基准上加测了显存占用：同等规模下，训练峰值显存约为
注意力基线的 60%，长序列下差距随长度继续扩大（数字为合成夹具）。
