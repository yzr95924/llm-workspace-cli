# Tags

> agent 在 ingest / query 中遇到新 tag 时，直接追加到本文件白名单，无需询问用户。
>
> 取值规则：tag 严格小写 kebab-case（与文件名一致）；单页建议 3-7 个，tag 过多说明
> 主题分散；白名单总数建议 10-20 个，可按主题复杂度增减。
>
> 格式（lint 解析依赖）：每行一条裸 bullet，两种形态：`- <tag>` 或
> `- <分类>：<tag1> / <tag2>`。分类前缀仅作展示、不入白名单，可用中文；多个 tag 用
> `/`、`，` 或 `,` 分隔。bullet 不能包在 code block 或 HTML 注释里，lint 只读裸文本行。
> lint 解析不到任何 tag 时跳过白名单校验，不报错。
