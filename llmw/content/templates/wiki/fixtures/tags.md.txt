# Tags

> LLM agent 在 ingest / query 时遇到新 tag **直接追加**到本文件，无需询问用户。
>
> **取值规则**：tag 严格小写 + kebab-case（与文件名命名一致）；单页 `tags` 建议 3-7 个
> ——过多说明页面主题过散，考虑拆分或聚焦；一级 tag 10-20 个是建议值（**非权威
> 阈值**，按主题复杂度由用户 / agent 共同裁定伸缩）。
>
> **格式约束（lint 解析依赖）**：每行一条裸 bullet `- <tag>`，不能包在 code block /
> HTML comment 里——lint 只读裸文本；多个 tag 用 `/` `，` `,` 任意一种分隔（如
> `- 模型：model / architecture`）。lint 找不到任何 tag 来源或解析出 0 个 tag 时
> **静默跳过**（不报错）。
