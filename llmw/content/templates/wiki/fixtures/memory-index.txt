# MEMORY

> LLM agent 的持久化记忆索引（无 frontmatter；`<wiki-root>/AGENTS.md` 顶部
> `@MEMORY/MEMORY.md` 自动加载本文件全文；不展开 `@import` 的 agent 按 AGENTS.md
> 顶部 Read 指令兜底）。
>
> **条目形式按事实颗粒度选**：
> - **完整条目**——需要解释"为什么这么做"或"将来怎么用"（上下文 / 解决步骤 / 未来
>   如何避免）→ 建 `MEMORY/<slug>.md`（frontmatter **仅 `title` 必填**，`type` /
>   `created` / `updated` / `tags` / `description` 全 optional——与 wiki 内容页
>   5 必填规则解耦）+ 本索引加一行 `- <slug> — 一句话 → [正文](<slug>.md)`
> - **短条目**——纯 reminder / 单一偏好 / 无需 why + how → 索引行直接
>   `- 一句话事实`，不单独建 `.md` 文件
> - 两种格式可在本文件共存；lint `memory-not-indexed` 兜底"有 .md 但未索引"
>
> **纪律**：条目增删**只改本文件这一份**（`@import` 引用自动同步指向全文，AGENTS.md
> 不持副本，无漂移）；用户**不**直接编辑 MEMORY/；条目**不**在 `wiki/index.md`
> 列出、**不**要求 inbound 链接；正文按需 `Read MEMORY/<slug>.md`。
