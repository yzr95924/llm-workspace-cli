# MEMORY/

> LLM agent 的持久化记忆索引（无 frontmatter；随 `<wiki-root>/AGENTS.md` 自动加载本文件全文，会话常驻）。
>
> **条目格式**（与 yzr-memory-management skill 同契约，机械判据以其 memory_lint 输出为准）：
> - **文件条目**：需要解释"为什么 / 边界 / 证据"时建 `MEMORY/<slug>.md`，frontmatter 三件套
>   `name`（= 文件名 slug）/ `description`（一句话摘要）/ `metadata.type`（user / feedback /
>   project / reference 四选一），推荐 `metadata.scope`（约束对象）与 `metadata.modified`
>   （YYYY-MM-DD）；**不写** wiki 内容页那套 `type` / `tags`。落盘走
>   `llmw wiki write memory add --slug=... --title=... --description=... --type=...`（建文件 +
>   挂索引行，正文再 Edit），并在本索引挂一行 `- [<标题>](<slug>.md)：<一句话摘要>`
> - **短条目**：纯 reminder / 单一偏好 / 无需 why → 索引行直接 `- <标题>：<一句话事实>`，
>   不单独建 `.md` 文件
> - 条目按 `## <组名>` 分组（默认组 `## 索引`），新条目只追加到组末尾，不改写他行
>
> **纪律**：治理（记什么 / 合并 / 预算水位 / 体检）归 yzr-memory-management skill，预算数值
> 不在本文件镜像；用户**不**直接编辑 MEMORY/；条目**不**在 `wiki/index.md` 列出、**不**要求
> inbound 链接；手写路径先写条目文件再挂索引行（中断只留孤儿，不留死链）。
